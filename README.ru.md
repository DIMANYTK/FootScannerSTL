# FootScannerSTL

Экспериментальный iOS-сканер стопы на базе фронтальной камеры TrueDepth (`AVCaptureDepthDataOutput`), который снимает карту глубины и выгружает бинарный `.stl` (`foot_scan_ГГГГ-ММ-ДД_ЧЧ-ММ.stl`) с отсечкой по дистанции (5–50 см) и таймером на 5 секунд.

## Как собрано и установлено

- **Написано с помощью:** Gemini (Hydrogen 4)
- **Сборка:** Через GitHub Actions на облачной виртуальной машине macOS (`macos-latest`) в неподписанный `.ipa`
- **Установка:** Через Sideloadly с Windows-ПК на тестовый iPhone (`Boris`) по кабелю
- **Протестировано на:** iPhone 13, iOS 26.5

## Текущий результат и проблемы

Результат пока сырой и требует доработки в следующих версиях:

- **Лишние бугры и «горки»:** Одиночный кадр с TrueDepth содержит шум сенсора и ступенчатость глубины, из-за чего по поверхности идут лишние неровности и «горки».
- **Зазубрины и шипы по краям:** На границах объекта и резких перепадах глубины остаются рваные края и вытянутые треугольники.
- **Один ракурс:** Съёмка одним кадром без совмещения даёт неполную геометрию по бокам и шумные кромки.

Более сильное сглаживание, чистку выбросов и нормальную фильтрацию сетки добавим в следующих версиях.
